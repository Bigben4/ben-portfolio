# Ben's Portfolio

This repository contains the code for Ben's Portfolio, structured as a monorepo with separate frontend and backend directories.

## Project Structure

- **[frontend](file:///home/loner/ben%20portfolio/frontend)**: The React + Vite frontend application.
- **[backend](file:///home/loner/ben%20portfolio/backend)**: The Node.js + Express backend service.

## Getting Started

### Frontend

To run the frontend dev server:
1. Navigate to the `frontend` folder:
   ```bash
   cd frontend
   ```
2. Run the development command:
   ```bash
   npm run dev
   ```

### Backend

To run the backend dev server:
1. Navigate to the `backend` folder:
   ```bash
   cd backend
   ```
2. Run the development command:
   ```bash
   npm run dev
   ```
